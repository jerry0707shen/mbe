# MBE 刷题器

使用网址：https://jerry0707shen.github.io/mbe/

前端由 GitHub Pages 托管。账号、做题进度、题库和原 PDF 存放于用户自己的 Supabase 私有空间。仓库没有 PDF、原题、答案或实际学习记录。

## 登录后自动准备

同一账号在新设备登录后，自动核验并载入全部云端题库，不用重新上传 PDF 或手动点击下载。题目在本机缓存以便重复使用；查看原页时才自动取得对应的私有 PDF，并验证文件哈希。已保存的缓存可在网络不稳定时继续使用。

题库正在准备时会显示进度。同步失败会明确提示，保留已有缓存。用户正在作答时暂缓替换题库。旧版本机题库在发生替换时另存账号内的本机归档；原有做题记录不会被题库更新重置。

新增题库仍只需在一台设备导入一次，并勾选私有云备份。其他设备下次打开、切回页面或定期检查更新时自动准备。上传到 GitHub 的是网页代码；原 PDF 继续由私有存储保护。

## 自由做题

首页点击“立即开始自由做题”，不需要设置题数或倒计时。按所选科目和伴读章节练习，优先出现未做过的题。当前题池走完后可继续下一轮，保留上一轮记录；退出后可继续上次进度。

原有定量练习、考试模式、错题本、统计和 NCBE 模考继续可用。NCBE 默认保留在独立模考中，未自动纳入日常自由题池。

## 按七科伴读章节练习

目录取自用户现有七科《SmartSheets 原文与伴读》原生书签：90 个章、493 个小节，保留原顺序。

- 首页可筛选整章或具体小节，作用于自由做题和定量练习。
- 1,096 道已在伴读收录的学习题提供内容指纹映射。只有当前题库的题干和 A–D 内容指纹完整相符时，才标为“伴读精确匹配”。这不是对全部上传题库的法律答案再审核。
- 未精确匹配的题通过在浏览器内运行的分节模型提出建议，标为“自动建议，可调整”。低可信匹配保留“待分节”，不强行宣称已核准。
- 在题目下展开“伴读分节”可以更改归类，调整随账号同步；可随时恢复自动分节。
- 不重新编号、不改动原题或选项、不把已学重做成绩标为未见题测试。保留独立 NCBE 模考题库。

`sections-data.json` 只包含目录、单向内容指纹和数字化主题特征，不含题干、选项、答案或讲义正文。分类训练仅使用伴读中已发布题目的明确白名单，没有读取封存题用于训练。自动建议没有冒充逐题人工核验。

## 备份与账号隔离

每个账号有独立的本机数据库和云端空间。未登录时的旧数据不会自动移入账号；首次迁入可点击“更多 → 导入本机旧数据”，原数据继续保留。旧 Claude 页面上的记录需先导出 JSON 后在此页面导入。

做题记录、笔记、标记和章节调整自动合并；同一未完成题组的状态采用较新版本，避免在两台设备同时操作同一个未完成题组。离开设备前等待“进度已同步”。原 PDF 需另行保留；JSON 备份只含进度、笔记和题组，不含 PDF 或原题。

建议定期导出 JSON 备份。浏览器可能清理缓存；已有云端备份会自动重新准备。免费云服务的额度与暂停规则以 [Supabase 当前说明](https://supabase.com/pricing) 为准。没有任何到期自动删除或二月份自动停用的应用设置。

## 后端与维护

项目使用 Supabase Auth、PostgreSQL 和 `mbe-private` 私有 bucket。公开的 `cloud-config.js` 仅包含项目 URL 和 publishable key，不应写入数据库密码、service-role key 或 secret key。数据库和文件访问均通过用户 JWT 及 RLS 限制。

- `backend/setup.sql`：新项目完整初始化。
- `backend/section-overrides.sql`：已有 V1 项目增加章节调整合并支持，保留现有数据。
- Auth Site URL 和 Redirect URL：`https://jerry0707shen.github.io/mbe/`。
- `cloud.js`：账号、同步、自动题库准备与 PDF 载入。
- `study.js`：伴读目录、分节匹配和手动调整界面。
- `vendor/`：固定版本官方 SDK 2.118.0，含来源、哈希和许可证。
